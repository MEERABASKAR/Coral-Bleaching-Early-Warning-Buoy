# Coral Bleaching Early-Warning Buoy

## Project Overview

The Coral Bleaching Early-Warning Buoy is an IoT-based marine environmental monitoring system developed to monitor underwater temperature and light intensity for identifying environmental conditions associated with coral bleaching. The system integrates sensor-based monitoring, wireless communication, and an alert mechanism to support early detection and marine ecosystem conservation.

## Project Objectives

- Continuously monitor underwater temperature and light intensity.
- Identify abnormal environmental conditions associated with coral bleaching.
- Generate immediate alerts through visual and audible indicators.
- Enable real-time remote monitoring through Wi-Fi connectivity.
- Promote coral reef conservation and marine biodiversity protection.

## Proposed System

The proposed system uses a NodeMCU ESP8266 microcontroller interfaced with a DS18B20 waterproof temperature sensor and an LDR light sensor. The microcontroller processes sensor readings and compares them against predefined threshold values. Under normal conditions, the green LED indicates a safe state. When abnormal conditions are detected, the red LED and buzzer provide warning alerts. Wi-Fi connectivity enables remote monitoring through an IoT dashboard.
